# Curious Minds — FAQ Accordion

A responsive FAQ accordion built with React and Tailwind CSS. This project presents interesting questions about science, space, and the human body in a clean and interactive layout.

## Features

- Expandable and collapsible FAQ items
- Smooth open and close transitions
- Animated SVG icons
- Responsive layout
- Reusable Accordion component
- Dynamic questions and answers through props

## Built With

- React
- JavaScript
- Tailwind CSS
- SVG

## What I Learned

- Managing component state with React's `useState` hook
- Passing data between components using props
- Creating reusable React components
- Using Tailwind CSS for responsive styling
- Implementing CSS Grid transitions for accordion animations
- Working with SVG elements and CSS transforms

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_PROJECT_DIRECTORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
